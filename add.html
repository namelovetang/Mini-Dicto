ID จะสร้างจาก "คำศัพท์ + Pinyin"
爱 + ài → ai-u7231 矮 + ǎi → ai-u77ee 行 + háng → hang-u884c 行 + xíng → xing-u884c
ดังนั้นคำที่อ่านเหมือนกันจะไม่ใช้ ID เดียวกัน และตัวอักษรเดียวกันที่มีหลายเสียงก็สามารถแยกกันได้

เช่น 行 + háng และ 行 + xíng ถือว่าเป็นคนละรายการ
